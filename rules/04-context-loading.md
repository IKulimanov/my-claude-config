# Context Loading

- Always-on слой держи маленьким. Стек- и доменные знания - это `skills/`, а не `rules/`.
- Skill должен загружаться по соответствию `description` задаче, а не "на всякий случай".
- Если задача затрагивает несколько слоёв (например, API + DB + Kafka) - загрузи несколько узких skills, а не один "всеобъемлющий".
- Локальный `CLAUDE.md` проекта перекрывает любые общие skills, если они конфликтуют.
