# Core Operating Model

Глобальные «plan-first», «прочти CLAUDE.md», «не правь чужие файлы» уже встроены в системный промпт. Здесь живёт только то, что специфично для рабочего процесса автора.

- Локальный `CLAUDE.md` имеет приоритет над любыми внешними «best practices». Если они конфликтуют — побеждает `CLAUDE.md`.
- На нетривиальной задаче сначала загрузи нужный *skill* по стеку (Java/Go/Web/DevOps), а не пытайся отвечать general advice'ом.
- Перед изменением API, схемы БД, Kafka-контракта или внешней интеграции — план и явное подтверждение от пользователя.
- Профиль **work** (rule 09): ожидай Jira ID (формат `[A-Z]+-\d+`) в названии ветки и в сообщениях
  коммитов; не предлагай PR/branch без него. В профиле **personal** Jira ID не требуется и не спрашивается.
