# HTML-отчёт

Шаблон - `~/.claude/my-claude-config/playbook/templates/report-template.html`. Скопируй его и замени содержимое
`<main>` и оглавление. Стили и скрипт не переписывай: все отчёты выглядят одинаково.

## Когда

Анализ, исследование, статистика, аудит, обзор дизайна, сравнение вариантов, разбор инцидента: документ читают,
в нём есть схема, график или больше трёх таблиц. Для README, ADR, задач, `plan.md`, `tests.md`, `summary.md` - markdown.

## Где лежит

- Отчёт по задаче: `.claude/tasks/<ключ>/<имя>.html`.
- Отчёт по проекту или аудит: `docs/<тема>-<ГГГГ-ММ>/<имя>.html`.
- Один файл без внешних ресурсов: без шрифтов, скриптов и картинок по сети. Файл должен открываться без интернета.
- На claude.ai не публиковать, если пользователь не попросил.

## Состав

1. Вывод (`section.summary`): 3-5 строк, понятны без остального документа.
2. Данные: таблицы, схема, график. Каждое число - с единицей и источником.
3. Что сделать: `ul.todo` с настоящими чекбоксами, одно действие в строке. Галочки хранятся в `localStorage`.
4. Подробности: `<details>` с содержательным `<summary>` и числом в скобках. Сюда идут отклонённые варианты, сырые
   данные, логи, источники.

Оглавление нужно при четырёх и более разделах. Раздел без содержимого удалить, а не оставлять пустым.

## Схемы и графики

- Только встроенный SVG. Цвета через классы шаблона (`box`, `edge`, `bar`, `axis`, `muted`), иначе сломается тёмная тема.
- Схема: до 7 блоков, слева направо, стрелки подписаны тем, что по ним идёт.
- График: столбцы для сравнения, линия для ряда во времени. Значение подписано у точки или столбца. Ось начинается с нуля.
- График ради одного-двух чисел не нужен: это предложение.
- Под каждой фигурой `figcaption`: что показано, единица, источник.

## Проверка

- [ ] файл открывается двойным щелчком без сети;
- [ ] светлая и тёмная тема читаются, схема не выцветает;
- [ ] вывод наверху отвечает на вопрос, с которым придёт читатель;
- [ ] галочки сохраняются после перезагрузки;
- [ ] при ширине 400 px нет горизонтальной прокрутки страницы (таблицы в `div.scroll`);
- [ ] в тексте только символы с клавиатуры (правило 07).
