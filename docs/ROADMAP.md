# История изменений конфига

Не список идей. Новое добавляется только по данным месячного аудита (`scripts/audit/`),
не по каталогу «что бывает у других». Лимит — не больше 7 изменений за раз, удалять больше,
чем добавлять. Открытые пункты живут в `CLAUDE.md` («Текущий фокус»), а не здесь.

## 2026-09-04 — переезд на новую машину и аудит конфига

Конфиг был установлен на новой машине и сразу дал данные: три ложных срабатывания хука секретов
за первые минуты, молчаливо отключённая проверка перед push, 51 мс на каждый логирующий хук.

- Отвязка от прежней машины: компоненты `config` (symlink репозитория в `~/.claude/my-claude-config`)
  и `workspace` (каталоги work/personal из `workspace.conf` → `~/.claude/workspace.md`).
  Абсолютные пути прежней машины убраны из 14 файлов.
- `rules/09-project-profiles.md` — профили work и personal. В personal командный процесс
  (Jira ID, staging-flow, коды Sonar, каноническая конвенция) не применяется, качество кода остаётся.
- `block-secrets.sh` переписан: для Bash проверяются аргументы читающих команд, а не вся строка.
  Регрессия — `tests/test-block-secrets.sh` (14 случаев, включая три реальных ложных срабатывания).
- `block-push-secrets.sh` пишет `kind: "scan-skipped"` в `blocks.jsonl`, если `trufflehog` не установлен.
- Логирующие хуки переведены в `async`, добавлена ротация журналов при 20 МБ.
- `permissions` (allow/deny) и `cleanupPeriodDays: 90` ставит установщик; свои разрешения
  пользователя не затираются. Регрессия — `tests/test-settings-merge.sh`.
- Context7 MCP подключён в user-scope.
- Удалено: недельный пайплайн `analytics/` (остановлен с июля, дублировал месячный аудит),
  `digest-routine.md`, `docs/AI_USAGE_AUDIT_2026-07.md`, skill `go-service`, `__pycache__` из git.
- Язык: правило TDD, форматы вывода команд и ответы reviewer-агентов переведены на русский.
