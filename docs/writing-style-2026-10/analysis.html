Тон и формат текстов: что работает у других

2026-10-02my-claude-configветка feat/writing-style

Правила стиля держатся, когда у каждого требования один владелец и тот слой, который срабатывает в нужный момент: тон чата в стиле вывода, символы в хуке, навыки писателя в скиле.

  • Правила из CLAUDE.md в длинной сессии слабеют. Стиль вывода уходит в системный промпт с каждым запросом.
  • Работают проверяемые формулировки ("первое предложение - результат"), общие ("будь краток") забываются.
  • То, что должно соблюдаться всегда, проверяет скрипт, а не модель.
  • Источники слабые: блоги, README скилов, обсуждения. Замеров с контрольной группой нет.

6. Подробности

Что отложено (4)
  • Проверка ответов в чате хуком на Stop: каждое срабатывание стоит повторной генерации. Решение после аудита 15.11.
  • HTML-вид плана скриптом из plan.md: без токенов модели, но нужен свой рендер markdown.
  • Чистка символов в playbook/sdlc.md, остальном плейбуке, docs/ и README.md.
  • Проверка комментариев в коде хуком: для них действует только правило 07.
Как хук решает, что проверять
  • Событие PostToolUse, инструменты Edit, Write, MultiEdit; файлы .md, .markdown, .html, .htm, .txt.
  • Берёт только добавленный текст: content, new_string, edits[].new_string. Старые строки файла не дают предупреждений.
  • Пропускает блоки кода, inline code, в HTML ещё style, script, code, pre.
  • Пропускает пути: skills/synced/, skills/writing/references/, hooks/data/, tests/, sonar-rules.md.
  • Ответ: additionalContext со списком символов, замен и штампов. Запись файла не отменяется.
  • Журнал: blocks.jsonl, kind:"prose", decision:"warn".
Качество источников

Официальных источников два: документация Claude Code про стили вывода и хуки, пост Anthropic про HTML. Остальное - опыт отдельных авторов. Статья terseai приводит одно измерение (файл 8400 и 2900 токенов) и не сравнивает качество ответов. Оценка "20%" из issue 37254 - впечатление автора. Вывод "стиль вывода держится лучше CLAUDE.md" опирается на механику из документации и на отзывы, а не на эксперимент. Проверить его можно своими логами на аудите 15.11.

Источники (9)
  • Claude Code: output styles: как стиль попадает в запрос, чем отличается от CLAUDE.md, скилов и хуков.
  • Claude Code: hooks: формат ответа PostToolUse, additionalContext.
  • Anthropic: The unreasonable effectiveness of HTML: для каких документов HTML, приёмы, цена в токенах.
  • blader/humanizer: 26 приёмов по шести группам, второй проход по своему тексту.
  • hardikpandya/stop-slop: фразы, структуры, примеры; оценка по пяти шкалам (не взяли).
  • Обсуждение на Hacker News: CLAUDE.md слабеет с ростом контекста, стили вывода держатся лучше.
  • Issue 37254: правила против поддакивания из CLAUDE.md держатся одну-две реплики.
  • terseai: Your CLAUDE.md is 3x too long: короткие повелительные пункты.
  • mejba.me: output style: какой слой чем владеет, вред жёстких лимитов длины.
