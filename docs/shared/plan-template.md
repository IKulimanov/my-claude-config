# Shared: шаблон плана реализации

Переиспользуемый формат плана для команд `/feature`, `/plan`, `/task`. Представь план на одобрение
до реализации.

```text
# Feature Plan: <name>

## Summary
<что меняется и зачем>

## Stack
<определённый стек и ключевые детали>

## Affected Layers
<см. docs/shared/affected-layers.md>

## Open Questions
- <только реальные блокеры: недостающие требования, развилки с трейд-офф, внешние зависимости,
  риски выката, безопасность. Очевидное не спрашивать.>

## Implementation Steps
1. <step> — <file(s)>
2. ...

## Tests
- Unit: <что и зачем>
- Integration/Component: <что и зачем>

## Migration (если применимо)
- <изменение схемы или данных>
```
