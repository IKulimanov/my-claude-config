# ADR-003: Хранение шаблонов скриптов

Дата: 2026-07-21
Статус: предложен

## Контекст

Шаблоны — параметризованный SQL, по которому исполнитель выполняет операции. Нужны
версии, ревью изменений DBA-администратором и фиксация «какой версией выполнено» в
журнале.

## Варианты

1. Репозиторий сервиса (папка ресурсов): версия шаблонов = версия сервиса, ревью обычным
   MR. Минус: правка шаблона требует релиза, DBA-администратору нужен доступ в репо
   разработки.
2. Отдельный репозиторий шаблонов: ревью MR — DBA-администратор, CI валидирует синтаксис
   и параметры, система подтягивает по тегу. Чистое разделение ролей, правка без релиза
   сервиса, но больше обвязки.
3. Хранение шаблонов в бд, это позволяет добавить в будущем конфигуратор шаблонов в дашборд

## Решение

Не принято.
